# Python Data Cleaning Project

This is a simple data cleaning project using Python and Pandas.

## Project objective
The goal of this project is to practice basic data cleaning steps on a sample dataset.

## Tools used
- Python
- Pandas
- Jupyter Notebook

## Main steps
- Load the dataset
- Check missing values
- Remove duplicate rows
- Rename columns
- Clean and organize the data
- Save the cleaned dataset

## Files
- `sample_dataset.csv`: raw sample dataset
- `data_cleaning.ipynb`: Python notebook for the cleaning process
- `cleaned_dataset.csv`: final cleaned dataset

This project is in progress.
